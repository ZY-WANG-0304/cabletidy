# CableTidy 0.3.0-rc.2

这是 `0.3.0` 的第二个候选版本，包含 Rust 迁移、安全审计、后台运行和开发环境更新。功能范围、安装要求、升级备份与恢复步骤见 [首个候选版本说明](0.3.0-rc.1.md)。试用本版本时，将其中的安装版本替换为 `0.3.0-rc.2`。

## 修复

`v0.3.0-rc.1` 的发布工作流在 Windows 并发启动锁测试中失败，未生成 GitHub Release 或完整发行包。原有目录重命名在目标锁已存在时可能返回“拒绝访问”；如果竞争实例随后释放了锁，后续检查会丢失竞争证据，导致启动报错。

本版本在 Windows 上使用不覆盖目标的原生目录移动调用，使已有锁返回明确的 `AlreadyExists` 错误。已有实例的锁不被替换，权限与共享冲突仍按原有有界重试逻辑处理。新增测试覆盖空目录、非空目录、已有所有者保留和释放后的成功发布，并保留并发启动压力测试。

## 发布与验收

GitHub tag 为 `v0.3.0-rc.2`。tag 工作流通过完整测试、五平台构建与安装验证后，自动创建 Pre-release 并附上 `package.tgz`、`SHA256SUMS` 和 `release.json`。本说明不代表产物已经可用；结果以对应提交的 Actions 为准。

npm 发布仍是独立步骤，候选版使用 `next`，不修改稳定版 `latest`。确认 npm 已发布后，可安装指定版本：

```bash
npm install -g cabletidy@0.3.0-rc.2 --registry=https://registry.npmjs.org/
```

npm 尚未发布时，可下载对应 GitHub Pre-release 的三个附件，核对摘要和来源后安装 `package.tgz`。

正式版前仍需完成旧版升级与恢复演练、真实 Codex / Claude 上游接入和 Windows 真实终端 Ctrl+C 验收。候选版不替代稳定版本；已推送的 `v0.3.0-rc.1` tag 保留，不移动或覆盖。

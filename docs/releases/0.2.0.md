# CableTidy 0.2.0

状态：待发布。变更范围：`v0.1.0` 之后合入主分支的更新。

## 新增

- Claude Code 原生接入 Anthropic Messages 兼容上游，支持普通与 SSE 请求、Token counting、显式配置的模型发现，以及 `x-api-key` / Bearer 上游认证。
- Claude Code 配置预览、应用与撤销：增量合并 `settings.json`，备份原文件，保留无关设置，并在接管字段被手工修改时阻止覆盖。
- Claude 模型映射支持搜索建议和自定义完整模型 ID，可选择家族别名、启动模型、子代理模型及模型发现；默认继续透传未配置的模型名。
- 首次启动时自动避开已占用的默认端口，保存实际端口供后续启动复用；同一数据目录通过跨平台实例锁防止重复启动。

## 修复与改进

- 加强 Linux、macOS、Windows 的实例身份检查与旧锁恢复，避免误接管暂停中的进程或被复用的 PID；改善 Windows Codex 查询子进程清理与文件替换重试。
- `status` 和无参数命令保持只读，尚未初始化时不创建配置、数据目录或密钥。
- 管理台刷新配置时合并可兼容的其他窗口修改并保留本地草稿，遇到冲突时暂停保存；Claude 预览聚焦实际应用字段，连通性检查使用上游 HTTP 可达性探测。
- CI 覆盖 Linux、macOS、Windows 的 Node.js 22.13.0 / 24 源码测试和安装冒烟测试；新增原生 Claude CLI 的本地模拟上游冒烟测试。

## 从 0.1.0 升级

停止正在运行的 CableTidy，再安装新版本并重新启动。正式发布后可执行：

```bash
npm install -g cabletidy@0.2.0 --registry=https://registry.npmjs.org/
cabletidy --version
cabletidy start
```

发布前可使用 `npm pack` 生成的 `cabletidy-0.2.0.tgz`，按 [README](../../README.md#从本地安装包使用) 安装。推荐 Node.js 24，完整版本要求仍为 `^22.13.0 || >=24`。

- 用户数据继续保存在 `~/.cabletidy` 或 `CABLETIDY_HOME`，升级后已有配置复用保存的端口；端口被占用时会明确报错，不会自动更换客户端地址。
- 上游密钥只读取本地 secrets store。旧 `envKey` 和 `env://` 环境变量引用不再生效；曾依赖这些方式时，需在管理台填写并保存 API Key。
- 早期原型的 `legacyCodex`、`targetOverrides.codex` 和 `codex.toml.v1` 格式不再自动迁移；仍使用这些字段的手工配置应先按当前配置格式更新。
- Claude 模型选择保存后需要重新应用客户端配置并重启 Claude Code。旧默认模型值不在候选列表时，会在下一次正常保存时清空，请先核对选择。
- 旧实例锁缺少可验证的身份信息时可能返回 `ELOCKUNKNOWN`。按 [README](../../README.md#安装与运行) 确认没有运行中或暂停中的实例后，处理提示的锁目录并重启，保留配置和密钥文件。

Claude Code 本版支持 Anthropic Messages 兼容上游；Bedrock / Vertex 原生协议转换、企业 HTTP/HTTPS 代理和内置 `claude gateway` 托管不在范围内。模型建议和连通性检查不保证上游模型能力或认证有效。

## 发布验证

维护者流程见 [安装与分发决策](../installation-research.md#npm-官方源发布流程)。`npm publish --dry-run --registry=https://registry.npmjs.org/` 会自动执行源码测试与安装冒烟测试；安装本机 Claude Code 后，可补充执行 `npm run test:claude`。正式发布前还需检查发布提交的三平台 CI 结果。

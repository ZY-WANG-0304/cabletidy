# CableTidy 0.3.0-rc.3

这是 `0.3.0` 的第三个候选版本，基于最新 `origin/main`，包含 `v0.3.0-rc.2` 之后的模型配置、上游代理和安全审计改进。Rust 迁移、后台运行和安全审计的整体范围见 [首个候选版本说明](0.3.0-rc.1.md)。

## 新增与修复

- 上游请求支持启动环境中的 HTTP / HTTPS / ALL_PROXY 与 NO_PROXY 设置，覆盖代理认证、HTTPS 隧道和 SOCKS 代理。修改环境变量后需重新启动 CableTidy。
- 上游模型配置改为以客户端模型名为键，保留迁移和编辑前的模型设置，避免模型映射调整导致设置丢失。
- 安全审计详情按请求与响应分组为可折叠面板，流式响应支持事件时间线与风险导航。
- 修复流式风险定位的错误响应高亮，以及切换详情时过期请求和旧坐标影响当前证据展示的问题。
- 移除旧的模型重写和审计捕获路径，统一现有流式处理与审计存储逻辑。

## 安装与升级

支持 Node.js `^22.13.0 || >=24`，推荐 Node.js 24。完整安装包包含 Linux x64 / arm64（musl）、macOS x64 / arm64 和 Windows x64 原生二进制，安装不需要 Rust。

升级前先停止服务，并备份完整 CableTidy 数据目录及 Codex / Claude 配置目录。`0.3.0` 候选版使用 `cabletidy stop`；从 `0.2.0` 升级时，在原终端按 Ctrl+C 或通过原进程管理器停止旧服务。配置在加载时迁移，升级后核对模型映射和可选设置；修改客户端接入设置后，预览并重新应用对应客户端配置。

确认 npm 已发布本版本后执行：

```bash
npm install -g cabletidy@0.3.0-rc.3 --registry=https://registry.npmjs.org/
cabletidy --version
cabletidy start
cabletidy status
```

npm 尚未发布时，可下载 GitHub Pre-release 的 `package.tgz`、`SHA256SUMS` 和 `release.json`，核对摘要与来源后使用 `npm install -g /absolute/path/package.tgz` 安装。回退时停止候选版，保留当前数据副本，安装旧版本并恢复升级前的数据及客户端配置备份；重装旧版不会撤销数据迁移。

## 发布与验收

2026-10-07 在 Linux x64、Node.js 25.6.0、Rust 1.98.1 上完成本地验证：版本一致性、Rust 格式检查、Clippy、完整 `npm test` 和发行包安装冒烟均通过。安装冒烟覆盖 CLI 版本、管理台资源、启动、停止、重启与卸载保留数据；本地测试包只包含当前平台二进制。

GitHub tag 为 `v0.3.0-rc.3`。tag 工作流执行完整测试矩阵、五平台构建及安装验证，通过后自动创建 Pre-release 并附上完整安装包、摘要与提交信息。构建结果以对应提交的 Actions 为准。

npm 发布是独立步骤，候选版使用 `next`，稳定版 `latest` 保持不变。GitHub Release 创建成功不代表 npm 已发布。

安全审计仍为仅记录模式，不阻断操作；没有风险发现不代表已经证明安全。正式版前仍需完成旧版升级与恢复演练、真实 Codex / Claude 上游接入及 Windows 真实终端 Ctrl+C 验收，自动化模拟上游测试不能替代这些验收。完整清单见 [维护者发布流程](../release-process.md)。

# 凭据保护

CableTidy 可在代理发送前，将模型上下文中的真实凭据 A 替换为随机占位符 B；收到响应后，把当前会话已知的 B 还原为 A。客户端和本地审计仍看到原文 A。此功能独立于 V1 风险检测；检测规则继续记录风险，不根据检测结果阻断或请求人工审批。

## 开启与配置

在管理台“设置 → 凭据保护”开启默认保护，在各线路的“凭据保护”中选择沿用全局、启用或关闭。默认关闭，保存后立即生效。

```json
{
  "credentialProtection": {
    "enabled": true,
    "mappingTtlSeconds": 3600
  },
  "virtualProviders": {
    "cabletidy_relay": {
      "credentialProtection": true
    }
  }
}
```

全局 `mappingTtlSeconds` 是会话闲置有效期，默认 3600 秒，可设为 60 秒到 30 天的整数秒。线路仅覆盖启用状态；移除线路字段恢复继承，线路导入导出保留此覆盖设置。

同一入口、协议和会话中的相同 A 使用相同 B。每个新请求重置会话倒计时，包括没有新凭据的请求；超过 1 小时没有请求时，默认映射过期。请求头标识在接收请求时续期，仅正文提供的会话标识在完整解析后续期。过期后的新请求建立新的 B；仍在执行的旧请求保留其映射用于响应还原。进程重启清空运行时映射。

会话身份复用现有审计归组：Codex 会话头、Claude Code 会话头和 `metadata` 会话标识；按入口与协议隔离。没有可识别会话标识时按单条请求隔离。会话标识是客户端报告，不能作为多租户身份认证。此前会话的实时映射也可用于还原 `previous_response_id` 等服务端历史引用产生的响应；映射已过期或重启后，不会从审计数据库重新激活映射。

## 处理范围

识别本地已保存凭据、常见 API Key、GitHub Token、AWS 凭据、JWT、私钥，以及凭据字段、赋值语句、Bearer、URL 认证参数和 Cookie 中的凭据。先扫描并学习请求全部凭据，再替换此前的相同出现；后续请求的普通正文也匹配同会话已学习的 A。服务器地址不替换。

B 格式为 `CTSEC_v1_` 加随机 UUID，共 40 个 ASCII 字符，不含 A 的片段或散列。只还原本次请求持有的同会话映射；未知 B、其他会话的 B 不读取任何 A。

支持 Responses 与 Messages 的 JSON 请求、普通 JSON 响应、UTF-8 文本错误响应、工具参数中的嵌套 JSON，以及常见 SSE 文本、拒绝和工具参数事件。SSE 按独立内容通道暂存可能属于 B 的尾部，跨片段完整匹配后还原，保持工具参数有效 JSON。JSON 字符串嵌套处理最多 4 层；不能承诺识别任意编码、二进制、图像、加密内容或模型改写后的 B。

签名、思考和加密字段不修改。若请求在这些字段或对象键中含已识别的 A，或者凭据字段不是字符串且无法安全替换，发送前返回 `422 credential_protection_failed`。若响应的签名或不透明字段含需要还原的 B、流式占位符不完整、响应无效或资源不足，终止响应并记录还原失败。保护失败不会回退到发送明文 A。

附加请求头、URL、查询参数、选定模型名也检查凭据，包括常见百分号编码。存在需要保护的凭据时拒绝转发这些参数。上游 HTTP 身份认证仍使用真实 API Key，这是连接上游所必需的认证，不属于模型上下文替换。

## 管理台与审计

会话轨迹概览的色块在发生实际替换或还原时显示小钥匙。详情页签顺序为：概览、风险、凭据保护、请求内容、响应内容、原始内容。

“凭据保护”展示 A↔B、是否复用、请求替换与响应还原次数、创建时间、本次请求重置的到期时间，以及定位原文按钮。到期时间是当时的证据时间，不是整个会话当前的实时倒计时；后续请求会继续续期。

请求、响应和原始内容展示 A。仅风险命中使用浅黄色背景，仅保护使用浅青绿色背景；同时命中时上半部浅黄色、下半部浅青绿色，并加青绿色底线，换行后每行保持相同样式。点击定位时叠加橙色外框。响应正文注明“还原后客户端响应正文”。普通 JSON 的高亮依据替换路径与偏移，流式原始正文保留指向重组内容快照的引用，关联流式内容显示 A 及保护标记。响应中原本存在的 A 不因另一处 B 被还原而自动标为已保护。

次数统计实际传输内容中的替换操作；SSE 的增量、done 事件和最终对象重复携带 B 时，各次还原分别计数，不代表不同凭据数量。只有发生操作才显示钥匙，开启但没有命中的请求不显示。

运行时映射仅驻留内存，受全局工作内存预算约束，闲置到期后不可复用并由后台回收；活跃请求保有的引用在结束后释放。暂存正文使用现有加密 Spool 和全局预算。完整 A↔B 证据作为分页正文快照存入本地审计库，跟随审计保留周期和容量清理，因此运行时过期或重启后历史仍可查看。审计数据库保留明文 A，应按现有本地原文审计要求管理；没有另存一套含 B 的实际传输正文。审计存储不足时明确标记证据不可用。

## 验证

自动测试覆盖同会话复用、并发一致性、闲置续期与过期、活跃旧请求还原、跨会话与未知占位符隔离、跨片段 SSE、Claude 交错文本和工具参数、嵌套引号/反斜杠/中文、失败前不联系上游，以及重启后的原文和高亮。浏览器验收覆盖桌面和手机上的设置、图标、六个页签、定位与原文展示。

```sh
npm test
node scripts/credential-protection-browser.mjs
```

浏览器脚本需已有测试二进制与 Playwright Chromium，可先执行 `node scripts/build-native.mjs --debug --test`。截图默认保存在 `.cabletidy-debug/credential-protection/`。

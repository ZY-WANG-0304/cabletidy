# Web 领域逻辑迁移到 Rust

审查基线：`origin/main` 的 `1867081`（0.4.0-rc.6）。实施分支：
`refactor/web-domain-to-rust`。本次重构记录并落实以下六项职责迁移。

| 项目 | 原前端职责 | Rust 归属与验收 |
| --- | --- | --- |
| 1. 配置身份 | ID 规范化、冲突处理、引用重命名、入口 URL | 复用 `config` 的规范化；操作结果返回最终身份与 URL，浏览器不再维护第二套规则。 |
| 2. 配置图编辑 | 创建 upstream / route / provider / cable，修改认证、分配 ID、删除无引用依赖 | 独立配置操作模块，复用 revision 检查、校验、密钥清理与原子保存；保留共享依赖、未知字段及未提交表单。 |
| 3. 模型编辑 | 改名、交换名称、删除、默认模型与 Claude 家族 / subagent 引用同步 | 操作携带旧名称，Rust 同步引用；原生别名保留，未登记模型透传继续可用，通用 normalize 不猜测改名关系。 |
| 4. 风险内容投影 | 证据读取、JSON 及嵌套转义解析、字段匹配、高亮范围、检测时内容 | 审计只读投影返回 finding IDs、范围与检测时版本；保持分页、资源预算、Unicode、取消及证据不可变。 |
| 5. 旧审计兼容与定位 | 旧 JSON 正文重建、结构路径转坐标、snapshot 来源推导、跨页找风险 | Rust 统一兼容正文与定位信息；旧 API 字段保持可读，不改写历史证据，不把未知位置标为有效命中。 |
| 6. 模型策略 | Codex 能力 / 输入类型 / 窗口字段生成、Claude 字段专属原生别名 | Rust 生成持久化模型设置并提供 Claude 选项；前端只读表单、显示选项及即时约束。 |

浏览器继续负责 HTML 转义与渲染、中文文案、单位和时间格式化、表单草稿与
三方合并、脏状态、导航 / 滚动 / 焦点、异步响应过期保护、轨迹可视化及已加载
内容过滤。Claude 官方建议模型列表仍是前端建议数据，不参与校验或路由。

迁移后的配置操作与已有整图 commit 接口共用保存机制；整图接口继续支持已有
调用方，不自动推断模型改名。审计投影是只读计算，不修改发现、正文或留存快照。

验证覆盖配置名称冲突与重命名、共享依赖删除、模型交换与原生别名、revision
冲突、Codex 官方目录限制、风险 JSON 字段与转义位置、流式检测版本、旧审计
数值键顺序、Unicode、证据缺口、分页及过期请求隔离。

六项迁移均已实施。配置编辑集中在 `src/config_operations.rs`，身份规则复用
`src/config.rs`，Codex 策略由 `src/catalog.rs` 生成，Claude 原生定义集中在
`src/targets/claude.rs`。证据匹配与旧正文兼容集中在 `src/security/evidence.rs`，
由审计读取接口返回投影；`web/config-identity.js` 与前端证据解析器已删除。
控制 API 的操作输入和审计投影坐标约定见 `docs/architecture.md`。

完成验证：`npm test` 通过 125 项 Rust 测试和 534 项 Node 测试（518 项普通
测试、13 项启动测试、3 项开发环境测试）。审计、线路导入导出、设置三套
Playwright 浏览器回归均通过，覆盖桌面和移动端。额外验证了旧凭据结构路径、
JSON surrogate pair、跨 UTF-8 正文段的完整凭据、超预算证据缺口和取消行为。

证据投影使用仅保存节点类型和源范围的轻量索引，每个展示字段供多条风险共同
匹配；转义映射只保存命中端点。检测保存参数来源路径、字节范围和版本指纹，
展示转换仍在读取阶段进行。定位分配受共享内存与每页 32 MiB 工作区预算约束，
耗尽时保留正文并返回 `riskGaps`。4 MiB、70 层嵌套参数的真实 HTTP 详情复测中，
首次读取进程峰值从约 353 MiB 降至 53 MiB，高亮和重复读取结果一致；该修复后
重新通过全部 Rust 测试、证据专项回归、Clippy 和审计桌面 / 移动端浏览器回归。

后续复核修复了嵌套重复键造成的“参数已变化”误判：按解码键名取最后值，
双向检查字段集合，保留嵌套严格相等。证据改为按当前项加载、完成后释放，
多项不再同时保留临时证据；重复扫描可取消，不增加完整去重键缓存。
127 项 Rust、520 项普通 Node 和 13 项启动测试通过，新增重复键 HTTP 及
1.4 MB 工作区下两项各约 600 KB 证据的回归通过，Clippy、审计桌面 / 移动端
浏览器回归通过。开发环境测试有 2 项通过，watch 重启退出测试失败；修复前
提交 `1822c58` 的对照构建在当前 Node 25.6.0 环境下同样失败。渐进高亮接口和
独立“计算中”状态另行实施，当前读取仍等待整页标注结束。
